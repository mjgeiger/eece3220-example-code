**11/7/2025**
A few notes about this repository:

* The intent of this repository is to organize all of the example code I have generated over the years.
   * That intent is not currently being met. I would classify the repository as "organized" at best.
   * The good news is that, as of yesterday, I've finally integrated Git with the VS Code install on my work machine and might actually make progress on organizing things the way I want.
   * The bad news is that (1) that organization will take a lot of time, and (2) I am the worst procrastinator I know, so it'll get done "at some point" ... in other words, possibly not at all.

* As for the current "organization":
   * Most subfolders contain example code related to a specific topic. For example, "string_examples" is shockingly full of code about working with strings. Most folder names are therefore (hopefully) self-explanatory.
   * Some of this code is horrendously outdated and should probably go away. I decided to go for completeness rather than utility in here. A lot of things are going to change as I go. See the note below for more.

* One final disclaimer: most of this code was written on the fly during lecture. As such, the usefulness of each file will vary dramatically. Some files will contain nicely written code with abundant relevant comments. Others will be barely one step up from spaghetti code. This can probably go without saying, but YMMV.
